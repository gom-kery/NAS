# Netflix Auto Skip (NAS)

Netflix 시청 중 반복적으로 발생하는 
**줄거리·오프닝 건너뛰기와 다음 에피소드 이동을 자동화**하기 위해 
제작한 Tampermonkey UserScript입니다.

## 주요 기능

- 줄거리 / 오프닝 건너뛰기 자동 처리
- 크레딧 구간 감지 후 다음 에피소드 자동 이동
- 다음 화 버튼 탐색 실패 시 재탐색 및 안전한 일시정지
- 콘텐츠별 다음 화 유도 시간 설정
- 타임라인 마커를 이용한 직관적인 시간 설정
- 플로팅 버튼 및 설정 UI
- 버튼 위치·투명도 등 사용자 설정 저장
- 도움말 및 디버그 모드 지원

## 구현 포인트

Netflix의 동적 플레이어 UI와 영상 상태를 지속적으로 감지하여 자동화가 필요한 시점에만 동작하도록 구현했습니다.

특히 다음 화 버튼이 화면에 표시되지 않는 상황에서는 플레이어 컨트롤러 표시를 유도한 뒤 버튼을 다시 탐색하는 fallback 로직을 적용했습니다.
